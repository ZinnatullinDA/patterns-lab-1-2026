# Лабораторная работа № 1. Интеграция программных компонентов с применением Adapter и Facade

## Цели и задачи

- Практически закрепить понимание шаблона **Adapter (Адаптер)**.
- Практически закрепить понимание шаблона **Facade (Фасад)**.
- Научиться интегрировать компонент с несовместимым интерфейсом.
- Научиться скрывать детали взаимодействия нескольких компонентов за упрощённым интерфейсом.
- Закрепить навыки модульного тестирования.

## Исходный проект

В проекте уже реализованы:

- интерфейс `BaseAnalogClock`;
- класс `AnalogClock`, хранящий время как положение стрелок и признак `AM/PM`;
- интерфейс `BaseDigitalClock`, с которым должен работать клиентский код;
- `ClockFormatter` для форматирования времени;
- `ClockHistory` для хранения истории установленных значений;
- пример клиентского компонента `DigitalClockDisplay`.

Проверьте исходный проект:

```bash
python -m pytest
python app.py
```

## Задание и порядок выполнения

1. Изучите интерфейсы `BaseAnalogClock` и `BaseDigitalClock`.
2. Реализуйте **Adapter**, который:
   - реализует `BaseDigitalClock`;
   - внутри использует существующий объект `AnalogClock`;
   - преобразует `datetime` в значения, необходимые аналоговым часам;
   - выполняет обратное преобразование в `datetime`;
   - корректно обрабатывает полночь, полдень, секунды и значения `AM/PM`.
3. Не изменяйте публичный интерфейс `BaseAnalogClock` ради упрощения адаптера.
4. Реализуйте **Facade**, предоставляющий клиенту компактный интерфейс работы с подсистемой часов.

   Фасад должен скрывать взаимодействие как минимум с:
   - адаптером;
   - `ClockFormatter`;
   - `ClockHistory`.

5. Минимальные операции фасада:
   - установка текущих даты и времени;
   - получение текущих даты и времени;
   - получение форматированного представления;
   - получение истории изменений.
6. Переведите `app.py` на работу через фасад.
7. Напишите модульные тесты для преобразований, пограничных значений времени, фасада и истории изменений.
8. Подготовьте структурную диаграмму и сохраните её в `docs/`.
9. Дополните README разделом **«Описание решения»**, отдельно объяснив назначение Adapter и Facade.

## Важное требование

Adapter и Facade решают разные задачи.

- **Adapter** преобразует один интерфейс в другой.
- **Facade** предоставляет более простой интерфейс к подсистеме.

Не следует объединять их в один класс только потому, что оба используются в одной лабораторной работе.

## Описание решения

**Adapter:** `DigitalClockAdapter` реализует `BaseDigitalClock` и содержит объект
`BaseAnalogClock` (по умолчанию `AnalogClock`). При установке `datetime` он
переводит часы, минуты и секунды в углы стрелок: соответственно 30°, 6° и 6°
на единицу. Угол часовой стрелки учитывает минуты и секунды, угол минутной —
секунды. Признак `AM/PM` различает первую и вторую половины суток; `0` и `12`
часов оба соответствуют углу 0°, но имеют разные значения этого признака.
Обратное преобразование восстанавливает дату и время по углам и `AM/PM`.
Дробная часть угла секундной стрелки сохраняет микросекунды. Значения
`datetime` с часовым поясом отклоняются, поскольку аналоговый компонент не
хранит смещение часового пояса.

**Facade:** `ClockFacade` создаёт адаптер, `ClockFormatter` и `ClockHistory` и
предоставляет четыре операции: `set_date_time`, `get_date_time`,
`get_formatted_date_time` и `get_history`. После успешной установки время
добавляется в историю. История возвращается неизменяемым кортежем; начальное
значение часов в неё не входит. `app.py` использует только фасад.

Структурная диаграмма находится в [docs/README.md](docs/README.md).
